# Software Testing 4 U

A responsive, multi-page static website for an online software testing and SDET learning academy.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Git / GitHub Pages

No build tools, package manager, backend or database are required.

## Run locally
1. Extract the ZIP file.
2. Open the `Software-Testing-4-U` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension if installed.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`, page footers and `pages/contact.html` with the academy's real email address.
2. Review the trainer biography and course syllabuses.
3. Replace sample YouTube links in `pages/tutorials.html` with your own published playlists.
4. Add your social links when ready.
5. Check every page and link on desktop and mobile.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload/push the contents of this project folder to the repository root.
3. In GitHub, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Contact form limitation
The starter contact form uses a `mailto:` action. It opens the visitor's configured email application and does not send messages directly from the website. For a more reliable web form, connect a form-handling provider or add a backend later. Do not put email passwords, private tokens or API secrets in public JavaScript.

## Editing course information
- Course catalogue data for the homepage is in `data/courses.js`.
- Individual course syllabuses are in `pages/courses/`.
- Shared styles are in `css/`.
- Shared navigation and interactions are in `js/`.

## Notes
This is a starter website implementation. Review all content, contact details, links and accessibility before making it the academy's public website.
